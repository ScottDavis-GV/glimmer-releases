# Glimmer releases

Installers and update files for [Glimmer](https://glimmerwidgets.com), desktop widgets for developers who lose track of time, made by [TechniQuest Associates](https://techniquestassociates.com).

Download the latest version from [Releases](https://github.com/ScottDavis-GV/glimmer-releases/releases/latest). Installed copies update themselves from here.

This repository holds releases only; the source code is private. Questions go to hello@glimmerwidgets.com.
